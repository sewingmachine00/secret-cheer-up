# Secret Cheer Notes

우리 반 친구들에게 익명으로 응원 메시지를 남기는 앱을 만들어줘. 메인 화면에는 닫힌 편지 봉투들이 나열되어 있고, 클릭하면 부드러운 애니메이션과 함께 칭찬 내용이 적힌 포스트잇이 나타나야 해. 메시지를 쓸 때는 귀여운 이모지도 하나 선택할 수 있게 해줘.
